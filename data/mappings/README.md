## Data Source

The FNDDS-to-FCID mapping dataset `FNDDS_to_FCID_mapping_final.csv` originally comes from the following research article: 

Conrad, Z. et al. Diet Sustainability Analyses Can Be Improved With Updates to the Food Commodity Intake Database. Front. Nutr. 9, (2022). [https://doi.org/10.3389/fnut.2022.868485](https://doi.org/10.3389/fnut.2022.868485)

The original dataset can be accessed here:

Conrad, Z. Food Commodity Intake Database, updated to 2018 (v3). DANS Data Station Life Sciences [https://doi.org/10.17026/dans-zqx-a23v](https://doi.org/10.17026/dans-zqx-a23v) (2022).

The remaining mapping datasets were manually constructed by the authorship team. See the manuscript and supplement files for more details.
